# Análisis y seguimiento del codelab

Fuente única: https://epanchanaf.github.io/tinyprice-codelab/ (consultada el 22 de octubre de 2026). Se leyeron íntegramente sus 16 artículos antes de modificar la aplicación. La navegación coloca TinyFish antes de Android, aunque los artículos del HTML tienen otro orden; este documento sigue la navegación.

La sección final enlaza `reference/README.md` y una instantánea completa de Android y Supabase. Sus instrucciones autorizan copiar esos archivos al proyecto creado con Empty Activity. Se utiliza esa referencia, sin rediseñar la aplicación ni añadir dependencias funcionales.

## Observaciones iniciales

- Ya existía `IATinyFish/` con el commit `37061d4`, que registra su creación mediante Android CLI y la plantilla oficial Empty Activity. No se afirma que se haya usado el asistente gráfico de Android Studio.
- Se conserva ese historial y no se modifica el segundo proyecto de plantilla situado en la carpeta superior.
- El teléfono conectado utiliza API 35, compatible con minSdk 23. Los SDK 37.0 y 37.2 están instalados.
- Se comprobó disponibilidad HTTP 200 de AGP 9.4.1, Gradle 9.6.0 y Compose BOM 2026.02.01 en sus distribuidores oficiales.
- El registro y verificación de TinyFish y Supabase permanecen pendientes mientras se desarrolla la parte independiente. No se simulan cuentas ni resultados remotos.
- Gemini CLI es opcional; su actividad interactiva no es un requisito de ejecución de TinyPrice.

Los resultados ejecutados se documentarán en `VERIFICACION.md`.
